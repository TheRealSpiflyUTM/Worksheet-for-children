# Resource formatting style

Use this style when adding or editing minigame resources in this Obsidian vault. This is the user's preferred format.

- Make each animal a numbered item with its name in bold: `1. **Hen**`, `2. **Duck**`, etc.
- Indent everything belonging to that animal by four spaces (like one Tab), so it stays nested beneath the animal name.
- Use the bold Romanian label `Părțile corpului:` followed by a numbered list of Romanian body-part names.
- Use the bold label `Imagine:` followed by an Obsidian image embed: `![[filename.png]]`.
- Store the image file alongside the resource note. The filename in the embed must match the actual image filename.
- Keep blank lines between the animal name, section labels, body-part list, and image embed.

## Example to copy

```markdown
1. **Hen**

    **Părțile corpului:**

    1. Creastă
    2. Ochi
    3. Cioc
    4. Bărbiță
    5. Aripă
    6. Corp
    7. Coadă
    8. Picior

    **Imagine:**

    ![[hen.png]]
```

For another animal in the same note, continue the outer numbering and restart its body-part list at 1. Match the body-part list to the parts indicated in that animal's worksheet image.
