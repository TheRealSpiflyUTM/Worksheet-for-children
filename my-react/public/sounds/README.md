# Worksheet feedback sounds

These WAV assets are the three Mixkit sounds selected for worksheet gameplay.

| File | Mixkit title | Item | Trigger |
| --- | --- | --- | --- |
| correct-answer-tone.wav | Correct answer tone | 2870 | Correct answer |
| wrong-answer-fail-notification.wav | Wrong answer fail notification | 946 | Incorrect answer |
| correct-answer-reward.wav | Correct answer reward | 952 | Completed mini-game |

Source collection: https://mixkit.co/free-sound-effects/game-show/

License: Mixkit Sound Effects Free License, https://mixkit.co/license/#sfxFree

Original downloads: `https://assets.mixkit.co/active_storage/sfx/{item}/{item}.wav`.
These are global gameplay assets; they do not add teacher-editable configuration fields.

The existing check-mark.mp3 is retained for compatibility with teacher widgets.
